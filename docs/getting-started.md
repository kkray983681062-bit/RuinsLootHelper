# 使用说明

完整解压下载的 Windows ZIP，保留 `_internal`，启动 **破晓装备助手.exe**。首次自动查找 Steam 游戏位置；找不到时再手动选择。

进入游戏角色后自动读取当前背包。主窗口关闭后继续监测，点击 **退出助手** 才会结束程序。

- **装备筛选**：词条、上技能、下技能分别设置。数值词条满足任意已启用规则即可显示，修改后点击 **保存设置**。
- **背包定位**：在主背包里圈出达标装备。自动识别顶部的锁并定位格子；跟随整理与移动。识别失败时可以辅助校准。
- **悬浮窗**：保留完全透明背景选项。悬浮窗的 **显示栏目** 控制栏目显示，拖动单根细线调整区域高度，鼠标滚轮或深色滚动条滚动内容。
- **进阶辅助**：先安装 / 更新随包提供的离线游戏组件，再重启游戏。开关不会因组件已连接而自动开启。

自动锁定先保护达标装备；自动回收依赖自动锁定。背包剩 1 格或已满时，确认达标装备已锁定后，回收所有未锁定物品。手动解锁后静默 30 秒，期间也暂缓回收。

自动开门只针对附近空间裂隙。等级 ≥50，或额外掉落率和额外极品率均 ≥300%，满足其一即可。本次助手通过后，切换角色仍可使用。

八卦入口提示在封印之地的八卦触发区域显示正确门红点；离开后隐藏。普通小地图有效，放大地图时隐藏。加入他人房间时，可能无法读取未复制的入口状态。

**项目与更新** 中蓝奏云下载会自动复制密码 `71my`。GitHub 无法访问时，更新检查可能失败，请到蓝奏云按文件名查看版本；功能使用不受更新检查失败影响。

设置保存在 `%LOCALAPPDATA%\RuinsLootHelper`。升级前关闭旧助手，完整解压新包，不要只替换 EXE。
