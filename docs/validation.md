## 尚有限制

- 自动开门与八卦入口提示的独立原型已有本机试用记录；合并后的 0.3.5 游戏组件仍需重启后核对。模拟游戏对象与只读背包检查不能证明所有原生动作都已在当前游戏内成功。
- 因此构建清单保持 `native_game_verified: false`，主动功能默认关闭。
- 部分 Tk 测试退出时仍有 `ThemeChanged` / 已销毁应用的回调提示；该轮测试结果为 OK，不据此声称所有运行期界面问题均已消失。
- 真正的独占全屏可能覆盖普通桌面悬浮层，可选择无边框全屏。
- GitHub 无法连接时只能提示检测失败并提供蓝奏云入口，不能据此判断已是最新版本。蓝奏云文件是否完成上传，以文件夹内实际版本和本次发行说明为准。
