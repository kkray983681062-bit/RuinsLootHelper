# 0.3.5 界面与进阶辅助发布计划

> 执行方式：使用 executing-plans 在当前任务内实施，不委派子任务。

**Goal:** 按用户确认的界面设计发布可用的 Windows 程序，并接入自动开门和八卦入口提示。

**Architecture:** 保留 Tk 与后台读取进程，使用共享主题、侧栏页面容器和独立原生功能卡片。复用已验证的空间裂隙与小地图投影代码，通过现有受时效约束的本地协议控制；不引入新的注入方式。

**Tech Stack:** Python 3.11、Tk、Win32、UE4SS Lua、PyInstaller。

**Spec:** 用户在本任务批准的渲染图和文案；以下约束为实施记录。

## Global Constraints

- 设置不透明深灰、暖白文字、少量金色；保留完全透明悬浮窗。
- 核心标题为“空位：N · 免费助手”；栏目为词条、上技能、下技能。
- 自动锁定与自动回收位于同一组，上下排列；回收依赖锁定。
- 自动开门：等级 ≥50 或额外掉落率、额外极品率均 ≥300%；一次助手会话通过后切角色保留资格。
- 八卦入口提示只绘制自己的红点，离开有效区域隐藏，不更改入口或传送。
- 保存设置始终可见；对话框居中；不展示拦截次数。
- 免费开源，保持个人快照、存档和一次性装备修改程序不公开。
- 用户取消 R2：蓝奏云作为主要下载入口，GitHub 在可连接时检查版本；未配置或未上传的渠道不得冒充已同步。
