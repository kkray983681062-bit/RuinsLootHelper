# 破晓装备助手

**完全免费，下载和使用均不收费。**

适用于 Steam 版《破晓之墟》（Ruins of Dawn）的 Windows 助手：装备筛选、背包定位，以及可选的自动拾取、锁定和回收。

## 下载

### [下载 Windows 完整版 · 0.3.4](https://github.com/kkray983681062-bit/RuinsLootHelper/releases/download/v0.3.4/RuinsLootHelper-0.3.4-Windows-x64.zip)

[GitHub 最新版本](https://github.com/kkray983681062-bit/RuinsLootHelper/releases/latest) · [蓝奏云下载](https://wwaou.lanzoup.com/b01giaqhvg)（密码：**71my**）

Windows 10/11 · 64 位 · 约 72 MB。游戏组件已随包提供，首次安装组件无需联网。

## 开始使用

1. 下载并**完整解压** ZIP，保留 `_internal` 文件夹。
2. 运行 **破晓装备助手.exe**，启动游戏并进入角色。
3. 首次使用原生功能：**功能设置 → 原生功能 → 离线安装／更新游戏组件**，安装后重启游戏。

助手会检查新版并提醒，点击下载后按提示替换完整程序目录。
