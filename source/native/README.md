# 进阶辅助游戏组件

助手 0.3.5 的可选组件，适配 Steam《破晓之墟》1.15、构建 24933058、Unreal Engine 5.5。装备筛选与背包定位可以独立使用。

Lua 在游戏线程中调用现有蓝图接口。助手与组件通过本机数据目录中的 `native-request.json`、`native-status.json` 交换有限字段，不执行请求文件中的代码。请求按当前角色、进程、会话及短时限核对；过期或退出后停止动作并隐藏入口提示。所有主动功能默认关闭。

## 功能

- **自动拾取**：调用角色原有拾取流程。先检查距离、归属、场景、菜单和背包空位，实际入包仍由游戏处理。范围可选 1 / 1.5 / 2 倍，间隔 1 / 0.5 / 0.35 / 0.15 秒，每批最多尝试 1 / 2 / 3 / 4 件。切出游戏、打开背包或菜单时暂停；背包满了静默暂停。
- **自动锁定**：按照助手的词条、上技能、下技能条件锁定装备。调用前核对格子及完整属性，手动解锁后静默 30 秒。
- **自动回收**：与锁定在同一张功能卡片中，需先开启自动锁定；确认达标装备已锁定，再按游戏设置执行回收。关闭锁定时同时关闭回收。
- **掉落屏蔽清单**：可搜索、勾选装备和 63 种图鉴。保留游戏原有屏蔽结果，再追加当前玩家的选择；已有地面物品仅跳过助手拾取，不删除背包或地面的物品。关闭清单开关会保留选择，但不再追加屏蔽。
- **自动开门**：自动开启附近空间裂隙，不自动传送。使用条件为等级 ≥50，或额外掉落率与额外极品率均 ≥300%。本次助手会话通过后，切换角色仍可使用；退出助手后重新判断。
- **八卦入口提示**：在封印之地的小地图上标出正确入口。离开有效区域、地图放大或请求失效时隐藏；不改变入口本身。加入他人房间时可能无法读取入口。关闭时不扫描，连续异常后暂停，重新开关可重试。

自动背包定位目前由助手识别顶部锁图标与 60 格布局；原生几何采集作为兼容模块保留。识别失败时隐藏标记，可通过辅助校准定位。

独占全屏无法保证普通桌面悬浮层可见。需要时可在进阶辅助中选择切换为无边框全屏。

## 验证范围

本版本对原生策略、模拟游戏对象、入口投影、开关及请求失效处理进行了本地回归。自动开门与入口提示的独立原型已有本机试用记录，但合并后的 0.3.5 组件仍需安装、重启游戏后核对，不能用模拟测试代替。最新验证范围见仓库 `docs/validation.md` 与对应发行说明。

## 安装与许可

在助手中打开 **进阶辅助 → 安装 / 更新组件**，正常退出游戏后安装，再重启游戏。UE4SS 固定版本随完整 ZIP 提供，安装无需联网；安装前校验 SHA-256，文件缺失或损坏会提示重新完整解压。

离线运行库：`_internal/runtime/UE4SS-2bfa839f.zip`。

- 上游下载：https://github.com/UE4SS-RE/RE-UE4SS/releases/download/experimental-latest/UE4SS_v3.0.1-1127-g2bfa839f.zip
- 源码：https://github.com/UE4SS-RE/RE-UE4SS/tree/2bfa839f
- SHA-256：`29367ce89f3637a537d507f2c79b9d33df3d145c63fd8bb0179f737a5ce46374`

本目录组件使用 MIT 许可，见 `LICENSE`。`json.lua` 来自 https://github.com/rxi/json.lua，保留其 MIT 许可。未启用控制台、CheatManager、热重载或示例按键 Mods。

## 回退

助手数据目录的 `native-install.json` 记录安装文件及散列。需要停用时先正常退出游戏，再移走由本助手安装的 `Binaries/Win64/dwmapi.dll`，下一次启动将不再加载组件。不要删除或覆盖已有的其他插件文件。
